# Individual Map · 个人素材库

把获奖、证书、项目、实习等经历和它们的证明文件集中存放，写简历时不再靠回忆、不再到处找文件；再用一张 3D「星图」把这些经历画成一张会发光、会放电的神经网络。

- **本地运行**：数据只存在你自己电脑上（SQLite + 普通文件夹），不上传任何地方
- **纯 Python 后端**：FastAPI + Jinja2 模板，前端只有少量原生 JavaScript，不需要 Node
- **离线可用**：3D 库已打包在项目里

## 功能

| 模块 | 说明 |
|---|---|
| 快速记录 | 首页顶部填个标题就能保存，可顺手拖入多个证书文件（分几次从不同文件夹拖入会累加） |
| 待归类 | 散落各处的证书、截图先一股脑丢进来，内容相同的文件只存一份；之后归到条目或“用它新建条目” |
| 文件归档 | 证明文件按 `年份/类型/` 自动重命名归档到 `data/vault/`，脱离本软件也能直接浏览；修改条目后文件自动跟着移动 |
| 关联经历 | 记录“这个奖来自哪个项目”“这个社团是在本科期间参加的”，两边都能看到，星图上是一条淡金色弧线 |
| 技能管理 | 统一技能名、设置类别（技术 / 工具 / 语言 / 软技能）、合并重复技能 |
| 时间轴 / 列表 | 按类型、年份、技能筛选；搜索覆盖标题、机构、描述、技能、文件名 |
| 完整度提示 | 缺时间、缺证明文件、成果没量化、缺技能标签等用橙色标签标出，可“只看待完善” |
| 导出与备份 | 导出 Markdown（可直接贴给 AI 写简历）；数据库 + 全部文件打包成 zip |
| ✦ 星图 | 3D 神经网络视图，详见下文 |

### ✦ 星图

素材库被画成三层结构：**我（中心）→ 类型分支 → 每条经历 ↔ 技能 / 机构**。数据再少也是一张连通的网，技能标签越多、网越密。

- 玻璃珠质感的小球、收敛的辉光、弯曲的“神经纤维”连线、景深雾、背景星空与浮尘
- 悬停：弹出信息卡，相关节点点亮、其余淡出；单击：镜头飞过去并打开详情面板
- 神经放电：每隔几秒一道信号从“我”出发，经类型分支传到某条经历，再传向它的技能
- 时间分层：整张网压成星盘，经历落在各自年份的轨道上（越早越靠里）；拖走小球时年轮亮起、拉出牵引线，松手后弹簧回弹
- 入场动画：打开页面时网络从中心逐层长出
- 成长等级：每条经历越充实等级越高，长出卫星（每颗代表一个证明文件或成果）、柔和的金色光晕，满级时还有偶尔一闪的十字星芒；被 4 条以上经历用到的核心技能套着一层旋转的晶体外壳；每个大类（教育、竞赛……）有 8 级，由下面所有经历累积而来，分支越多、写得越完整，大类就越大，每升一级多一样外观；升到 Lv3 时会分化出一条进化路线（恒星、行星、星云，或稀有的黑洞），由这个大类的数据倾向加一点运气决定，选定后不再改变。升级后下次打开星图会播放庆祝动画，信息卡里会提示“再补什么就能升级”
- 点亮进度：收集图鉴式的等级徽章，显示每一级有多少节点达到；点击直接飞过去，并提示“离升级最近”的大类和经历
- 低特效模式：电脑卡时关掉辉光、浮尘和放电

## 快速开始

需要 Python 3.10+（开发时使用 3.12）。

Windows 下双击 `start.bat`：首次运行会自动创建虚拟环境并安装依赖，然后打开浏览器 http://127.0.0.1:8765 。

手动启动：

```bash
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe run.py
```

## 数据存放

全部在 `data/` 目录（已在 `.gitignore` 中，不会提交）：

| 路径 | 内容 |
|---|---|
| `data/map.db` | 数据库（SQLite） |
| `data/vault/` | 证明文件，按 `年份/类型/` 整理 |
| `data/trash/` | 移除的文件先放这里，确认不要了再手动清理 |
| `data/backups/` | 手动导出的完整备份 zip |
| `data/backups/auto/` | 启动时自动做的数据库快照（数据有变化才做），保留最近 10 份 |

恢复数据库快照：先关掉程序，把快照复制成 `data/map.db`，再启动。升级数据库结构前程序也会自动先做一份快照。

设置环境变量 `IMAP_DATA_DIR` 可以换一个数据目录，用测试数据试新功能而不碰真实数据。

## 测试

```bash
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe -m pytest -q
```

测试自动使用临时数据目录，不会碰 `data/` 里的真实数据。

## 项目结构

```
app/
  main.py          FastAPI 应用入口，挂载静态文件和各路由
  config.py        路径与端口配置（IMAP_DATA_DIR）
  models.py        数据模型：条目 Entry、技能 Skill、证明文件 Attachment；条目类型 ENTRY_KINDS
  db.py            数据库引擎与会话，启动时建表并执行升级
  migrations.py    数据库升级（改表结构时在这里追加升级函数）
  backup.py        自动快照与完整备份
  vault.py         文件归档：去重、命名、移动、回收
  completeness.py  完整度检查规则
  web.py           模板与路由共用的工具（跳转提示、上传保存、静态文件版本号）
  routes/          entries 条目 / links 关联 / files 文件 / inbox 待归类 / skills 技能 / graph 星图 / export 导出备份
  templates/       页面模板（Jinja2）
  static/          style.css + app.js（素材库页面），graph.css + graph.js（星图）
  static/vendor/   打包好的 3d-force-graph + three.js
tests/             pytest 自动化测试
tools/graph-lib/   重新打包 3D 库的脚本（仅升级库时需要 Node）
docs/交接文档.md   开发交接文档：架构、实现要点、测试方法、已知问题、路线图
run.py             启动入口（自动打开浏览器）
start.bat          Windows 一键启动
```

## 路线图

1. ✅ 素材库：录入、文件归档、时间轴/列表、搜索筛选、完整度提示、导出备份、关联经历、技能管理、自动快照
2. ⏳ AI 辅助录入：导入旧简历、识别证书照片、整理杂乱文字、推荐技能标签、改写为 STAR 格式
3. ⏳ 按岗位挑素材：粘贴 JD，自动挑出相关经历并生成定制的简历条目，同时在星图上点亮相关节点
